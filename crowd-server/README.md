# crowd-server

観客が自分のスマホから連打して、ゲージを溜めて、画面を壊す。その**サーバ側**。
ミキサー(`vj-mix-spike1.exe`)とは別プロセスで動く。

設計と、なぜこうなっているかは [`../design/CROWD_CONTROL.md`](../design/CROWD_CONTROL.md)。

## 動かす

Node が要る(v18以上。`node --version` で確認)。**npm install は不要**
— 追加ライブラリを一切使っていない。

```
node crowd-server/server.js
```

起動すると、観客に配る URL と、自分用の調整ページの URL が出る。

```
  audience:  http://192.168.11.140:8777/
  VJ tuning: http://127.0.0.1:8777/vj?t=<毎回変わる合言葉>
```

- **観客用**の URL をスマホで開いてもらう(QRにすると楽。下記)
- **調整ページ**は自分の PC からしか開けない。会場の誰かに触られない

そのあと、ミキサーを `--crowd` 付きで起動するか、Controls の
`CROWD (audience phones)` にチェックを入れる。

### まとめて起動する

`start-crowd.bat` を叩くと、サーバとミキサーが順に立ち上がる。

## 会場で最初に確認すること

1. **スマホと PC が同じネットワークにいるか。** 会場 Wi-Fi は端末どうしの通信を
   遮断していることが多く、その場合スマホから PC に届かない。
   **モバイルルーターを持ち込むのが確実**
2. **Windows ファイアウォールが Node を許可しているか。** 初回起動時に出る
   ダイアログで「プライベートネットワーク」を許可する。ここを閉じると、
   自分の PC からは見えるのにスマホからだけ繋がらない、という状態になる
3. 調整ページの `ミキサー接続中` 表示。ここが `未接続` のままなら、
   ミキサー側の CROWD が有効になっていない

## QRコード

MVP では QR を自動生成しない(そのためだけにライブラリを足したくないため)。
**1回だけ**自分で作って `crowd-server/public/qr.png` に置けば、
`http://<PCのIP>:8777/qr.png` で表示できるので、それを投影する。

IP はルーターが変わると変わる。固定したいならルーター側で DHCP 固定にする。

## つまみ(調整ページ)

| 名前 | 何が変わるか |
|---|---|
| 溜まりやすさ | 1タップで増える量。上げると軽く溜まる |
| 抜けやすさ | 毎秒どれだけ減るか。上げると必死に叩かないと維持できない |
| 一発の長さ | ドカンと来てから収まるまでの秒数 |
| 再発火まで | 一発の後、次が出せるようになるまでの秒数 |

**効き具合(cap) / HOLD / 参加受付 はミキサー側**にある。本番中に一番触るものは
手元に置き、事前に決めるものはブラウザに置く、という分け方。

### 既定値だと何秒で満タンになるか

全員が全力(1人あたり毎秒5回)で叩いた場合。実際は毎秒4回くらいなので2割増しで見る。

| 人数 | 満タンまで |
|---|---|
| 1人 | **到達しない**(仕様。1人では漏れる量に勝てない) |
| 2人 | 約43秒 |
| 3人 | 約18秒 |
| 5人 | 約12秒 |
| 10人 | 約8秒 |
| 20人 | 約5秒 |

放置したゲージは約25秒で空になる。
**2人以上が押していないと発火しない**(1人で独占できないようにする明示ルール)。

## 荒らし・連打ツール対策

- 1端末あたり**毎秒5回まで**しか数えない。サーバ側で経過時間から計算するので、
  スマホが「100回押した」と嘘をついても増えない
- 同じ IP から作れる端末IDは4つまで
- 参加受付を閉じれば全部止まる。ミキサー側の `CUT` で効果だけ即ゼロにもできる

## テスト

```
node crowd-server/test/selftest.js   # ゲージの計算と通信フォーマット(18項目)
node crowd-server/test/e2e.js        # 本物のサーバを起動してHTTP+UDPで検証(19項目)
```

`e2e.js` は 8877/8878/8879 を使うので、本番用(8777等)とぶつからない。

## ファイル

| ファイル | 中身 |
|---|---|
| `server.js` | HTTP + SSE + UDP。ルーティングだけ |
| `gauge.js` | **手触りの本体**。溜まる/漏れる/発火/クールダウンの計算 |
| `packet.js` | ミキサーとのやりとり(20バイト固定) |
| `public/index.html` | 観客のスマホ画面 |
| `public/vj.html` | 自分用の調整ページ |
